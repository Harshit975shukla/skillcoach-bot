SkillCoach — CI/CD Pipeline (GitOps)

GitHub Actions tests the chart; a manual publish run builds ARM64 images, tags them with the full commit SHA and updates Git. Argo CD pulls the desired state. Proposed only; not deployed.

Open in any browser. Mermaid loads from a CDN, so you need internet the first time.
Orange = Terraform, run once by you to provision infrastructure. Everything else is the per-commit automated loop.
